# Aplikasi Daftar Kontak — Pertemuan 6

## Fitur
- ConvexAppBar: Kontak, Cari, Profil
- 20 kontak dummy dibuat menggunakan Faker
- ListView.builder untuk daftar kontak
- Tanggal Indonesia menggunakan intl DateFormat
- DropdownSearch untuk kategori offline (Semua, Keluarga, Teman, Kerja)
- AvatarGlow untuk foto profil

## Menjalankan
1. Pastikan Flutter SDK sudah terpasang.
2. Jalankan `flutter create .` jika folder platform seperti `android/` belum ada.
3. Jalankan `flutter pub get`.
4. Jalankan `flutter run`.

## Screenshot
Jalankan aplikasi pada emulator/perangkat, lalu ambil screenshot dari:
1. Halaman Kontak
2. Halaman Cari (coba pilih salah satu kategori)
3. Halaman Profil

Folder `screenshots/` disediakan untuk menaruh hasil screenshot asli dari aplikasi yang berjalan.
